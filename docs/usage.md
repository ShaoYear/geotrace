# GeoTrace 使用说明

适用版本：v1.0.0 ｜ 系统要求：Android 8.0 及以上

GeoTrace 的核心思路：**让手机记录时间与位置，让相机专心拍照**，回家后按拍摄时间把位置写回照片。

---

## 第一步：记录轨迹

1. 打开 GeoTrace，在首页点「**轨迹记录**」。
2. 首次使用请允许位置权限（选择「**使用应用时允许**」并授予「**精确位置**」）；若希望锁屏后持续记录，请按提示允许「**始终允许**」（后台位置）与通知权限。
3. 点「**开始记录**」。页面会实时显示：
   - 记录时长
   - 距离
   - 定位点数
   - 当前速度
   - GPS 状态与定位精度（例如「定位正常 · 精度 ±3 m」）
4. 记录过程中可以**锁屏、切后台、正常使用其他应用**，GeoTrace 以前台服务持续记录。
5. 部分手机（尤其国产 ROM）会在省电策略下清理后台：如收到引导，请把 GeoTrace 加入**电池优化白名单 / 允许后台运行**。
6. 中途可「暂停」，完成后点「结束」并为轨迹命名（不填会自动用日期命名）。

> 小建议：到户外开阔处再开始记录；GPS 记录间隔可在「设置 → GPS 记录间隔」调整，间隔越小轨迹越精细、耗电略高。

## 第二步：使用相机正常拍照

旅途中**不需要改变任何拍照习惯**，用你的相机正常拍摄即可。

只需注意一件事：相机的时钟要尽量准确。如果相机时间与手机差了几分钟也没关系——GeoTrace 提供「**默认时间偏移**」设置（在设置中以分钟为单位调整：相机慢于手机调大、快于手机调小）。

## 第三步：导入照片

有两种入口：

- **照片定位流程**：首页 →「照片定位」→ 选择轨迹 →「添加照片」；
- **照片管理**：底部「照片」Tab →「添加照片（可多选）」，不依赖轨迹，可先管理照片稍后再定位。

选择方式：

- **相册选择**：按相册（文件夹）浏览，支持多选、全选；
- **系统照片选择器**：可只授权本次选中的照片；
- 添加后在「**已添加内容**」中可以查看缩略图、继续追加或移除。

支持 JPG / JPEG / PNG / HEIC / HEIF；RAW 文件（RW2/ARW/CR3/NEF 等）会被识别并提示跳过，不会被修改。

## 第四步：自动匹配定位

1. 在「照片定位」页确认已选轨迹与照片。
2. 选择写入方式：
   - **创建副本（推荐）**：带 GPS 的新照片保存到 `Pictures/GeoTrace/Geotagged/`，**原照片完全不动**；
   - **覆盖原照片**：直接把 GPS 写入原文件（采用先复制、写入、再替换的安全流程）。
3. 开始匹配。GeoTrace 会：
   - 读取每张照片 EXIF 中的拍摄时间；
   - 套用时间偏移；
   - 在轨迹点中按时间查找相邻两点并线性插值，得到精确坐标（含海拔）；
   - 照片时间距最近轨迹点超过「**最大匹配时间**」（默认 5 分钟，可在设置中改为 1/3/5/10/30 分钟）时，**不会强行写入**，而是标记为无法匹配。
4. 完成后查看「定位结果」：成功数量、每张照片的匹配时间与经纬度、失败原因。

## 第五步：查看结果

在轨迹详情或「照片」Tab 中打开任意照片：

- 高清照片预览；
- 拍摄时间、位置（地址）、经纬度；
- 完整 EXIF：相机品牌/型号、尺寸、文件大小、焦距、光圈、快门、ISO、曝光补偿；
- 「照片地图」显示该照片的位置，可点全屏按钮查看大地图。

轨迹详情页的地图会画出整条轨迹，并用照片缩略图标出每张已定位照片的位置。

## 第六步：手动调整

对于没有匹配上、或你认为位置需要修正的照片：

1. 打开照片详情 → 点「位置」行的编辑（未定位照片显示「手动设置位置」）；
2. 在地图上**直接点选**落点，或在顶部搜索框输入**地点关键词**（景点、道路、POI）后从结果中选择；
3. 底部会显示已选地点名称与 WGS-84 经纬度；
4. 点「**确认此位置**」保存。定位来源会标记为「手动设置」。

批量处理：在「照片」Tab 的照片列表中多选照片后，可以**批量修改拍摄时间与位置**，处理过程中有进度显示。

## 权限说明

| 权限 | 为什么需要 |
|---|---|
| 精确位置权限（ACCESS_FINE_LOCATION） | 记录高精度 GPS 轨迹点，用于照片定位 |
| 后台位置权限（ACCESS_BACKGROUND_LOCATION） | 锁屏 / 切后台 / 手机放包里时继续记录完整轨迹；不授权则仅在 App 前台时记录 |
| 前台服务 + 通知权限 | Android 要求持续定位必须以前台服务运行，并在通知栏提示「正在记录」 |
| 电池优化白名单（可选） | 防止系统在长时间锁屏记录时杀掉记录服务 |
| 照片 / 媒体读取权限 | 读取你主动选择的照片及其 EXIF 信息；Android 13+ 可仅授权照片，Android 14 推荐使用系统照片选择器「仅所选照片」授权 |
| 网络权限 | 仅用于高德地图瓦片显示与地点搜索；**不会上传任何照片或轨迹** |

**隐私承诺（基于 v1.0.0 实际实现）：**

- 照片、轨迹、EXIF、匹配结果全部在本机处理与保存；
- GeoTrace 没有账号体系、没有服务器、不收集任何用户数据；
- 网络请求仅发生在地图显示与地点搜索时，由高德地图 SDK 发起；
- 删除照片记录只移除 GeoTrace 内的记录，不会删除你相册里的原文件。

## 常见问题

**Q：匹配出来的位置和实际拍摄点有偏差？**
A：先检查相机时钟与手机时间差，在「设置 → 默认时间偏移」中修正；偏差也可能来自 GPS 漂移，可在照片详情手动选点修正。

**Q：照片提示「无法匹配」？**
A：通常是拍摄时间不在轨迹时间范围内，或与最近轨迹点间隔超过最大匹配时间。可调大该设置，或手动定位。

**Q：原照片会被修改吗？**
A：默认不会——使用「创建副本」时原片保持原样，带坐标的是新文件。

**Q：轨迹可以导出到其他软件吗？**
A：可以，轨迹详情右上角「导出」生成标准 GPX 1.1 文件；也支持导入外部 GPX 轨迹用于匹配。

**Q：缩略图显示「文件已丢失」？**
A：说明照片原文件已被删除、移动或当前授权无法访问。该照片不可打开或操作；重新把照片放回原位置（或重新添加）即可恢复。
